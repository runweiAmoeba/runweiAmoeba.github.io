# Runwei Amoeba | GitHub Page

A stylish interactive portfolio with a 3D mesh net visualization.

## Project Structure

```
.
├── index.html          # Main landing page
├── prong.html          # Interactive 3D mesh page
├── css/
│   └── styles.css      # Global styles with neon-dark theme
├── js/
│   └── mesh.js         # Three.js 3D mesh animation
└── README.md
```

## Features

- **Prong Page**: Interactive 3D mesh of triangles that flows like water
  - Mouse drag interaction causes swishing/rippling effect
  - Touch support for mobile devices
  - Neon color scheme with purple/pink/cyan accents
  
- **Responsive Design**: Works on desktop and mobile
- **Glassmorphism UI**: Modern frosted glass aesthetic

## Usage

Open `index.html` in a web browser, or navigate directly to `prong.html` for the 3D mesh experience.

## Tech Stack

- Three.js (r158) - 3D rendering
- CSS3 - Glassmorphism, gradients, animations
- Vanilla JavaScript - Interactivity
